# Tejada Financial PWA

Tejada Financial is a lightweight Progressive Web App (PWA) designed as a public-facing digital banking platform demonstration.

The application focuses on a clean user experience, modern branding, and mobile-friendly access. It includes a responsive landing page, company information, contact details, and PWA capabilities for installation on supported devices.

## Features

* Modern fintech-inspired interface
* Progressive Web App architecture
* Installable mobile experience
* About and Contact information pages
* Responsive design for desktop and mobile devices

## Purpose

This project demonstrates the design and presentation layer of a modern digital financial platform, showcasing user experience concepts and web application capabilities.

## Technology

Built using:

* HTML5
* CSS3
* JavaScript
* Progressive Web App technologies

## Status

Development preview / demonstration project.
